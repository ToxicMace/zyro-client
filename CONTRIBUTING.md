# Contributing to Zyro Client

Thanks for helping out!

- Report bugs and ideas in the [issue tracker](https://github.com/ToxicMace/zyro-client/issues).
- Pull requests are welcome; keep them focused and describe what changed.

## Building

See the [README](README.md#building). In short: `SQLX_OFFLINE=true cargo run -p zyro_app` runs the launcher, and the game mod lives in `mods/zyro-client` (one Gradle build per Minecraft version).
